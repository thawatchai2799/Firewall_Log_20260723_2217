§3 Datasets

None of the three datasets is redistributed here. All are public:

  • Dataset A — Ertam & Kaya Internet Firewall Data Set (65,532 rows): kaggle.com/datasets/tunguz/internet-firewall-data-set
  • Dataset B — CIC-IDS2017 (2,830,743 rows): unb.ca/cic/datasets/ids-2017.html
  • Dataset C — UNSW-NB15 (2,540,047 rows): research.unsw.edu.au/projects/unsw-nb15-dataset

After downloading, point DATASET_PATHS in dataset_config.py at your local copies. Note that the UNSW-NB15 feature-name file is officially spelled NUSW-NB15_features.csv.

§4 Reproducing the results

pip install -r requirements.txt
# edit dataset_config.py so DATASET_PATHS matches your machine
run_all.bat          # Windows;  ./run_all.sh on Linux/macOS

Individual stages run alone with run_all.bat main | focal | pgd | shap. Stage 1 is the long one and is resumable: it checkpoints after each unit (one fold × one technique × one dataset), so an interrupted run restarts with the same command and skips completed work.

Protocol notes that matter when comparing runs

  • Folds. All cross-validation uses StratifiedKFold(n_splits=5, shuffle=True, random_state=42). The gamma sweep reuses exactly these folds, so its numbers are directly comparable with Table 5.
  • Epoch counts differ by design. RQ1–RQ3 train for EPOCHS=100. The adversarial experiments train for 150 epochs to match the original Section VI-D FGSM protocol behind Table 8.
  • FGSM and PGD share their models. pgd_attack.py trains the two models once and evaluates both attacks on them, so the comparison carries no cross-run training variance. Global seed 42.
  • The Section VI-C3 SHAP model is not an RQ1 fold model. It is trained on a stratified 400,000-row subsample (minority classes kept in full) and used for explanatory analysis only; no per-class score in the paper comes from it.
Known deviation. Section VI-E was run before seeding was unified, which is why its clean-accuracy cost is 23.3 points against 12.5 in Section VI-D. This is stated as a limitation in Section VII-C. The seeded PGD re-run reproduced the Table 8 FGSM figures within 1–2 points, which localises the variance to the Section VI-E retraining rather than to the protocol itself.

§5 The three follow-up experiments

5.1  Focal loss gamma sweep → Section VI-A

Sweeps gamma over {0.5, 1.0, 2.0, 5.0} on Dataset A using the same folds as the main experiment. Reported in text only; the figure is provided here but is not in the manuscript.

python focal_loss_gamma_sweep.py --dataset ertam_kaya

The best value (gamma=1.0, macro-F1 0.7082) does not significantly beat the default gamma=2.0 (0.6966; Wilcoxon p=0.3125, Cohen's d=1.19), and no gamma improves the reset-both class beyond F1=0.019. At gamma=0.5 the model collapses to the majority class in all five folds (macro-F1 0.1824, std 4e-06). This supports the claim that focal loss's weakness here is inherent rather than a tuning artifact.

5.2  PGD-10 → Sections IV-F and VI-D, Fig. 9

Madry-style PGD: 10 steps, random start inside the epsilon ball, step size 2.5×epsilon/10, projection after every step, same perturbation mask as FGSM (port fields locked).

python pgd_attack.py

Against the standard model PGD adds essentially nothing (within 0.4 points of FGSM at every epsilon) because the single-step attack already compromises it. Against the adversarially trained model PGD is modestly stronger (attack success 15.6–20.3% versus 10.7–16.1%) but robust accuracy stays in the same flat regime. The protocol block of pgd_attack_results.json records every setting used.

5.3  SHAP for the hardest Dataset C classes → Section VI-C3, Fig. 8

Protocol identical to Section IV-E: baseline-SMOTE model, KernelExplainer, 50-sample background, up to 100 explained test samples per class (all 44 available for Worms).

python shap_hard_classes.py --max_train_samples 400000

Two different failure modes. Backdoors depends almost entirely on protocol (mean|SHAP| = 0.0367, about 24× the next feature) — an insufficient shortcut. Worms has no feature that moves the output at all (every mean|SHAP| on the order of 1e-4). Both classes were misclassified in every explained sample, predominantly as Exploits.

If the script exits with “Target class not found”, it prints the available class names; re-run with --targets set to the exact spellings in your copy of the data.

§6 Known deviations and limitations

These are stated in Section VII-C of the manuscript and repeated here so that nothing in this repository is more reassuring than the paper itself.

  • The technique ranking is not statistically certified. With five folds the minimum attainable two-sided Wilcoxon p-value is 0.0625, so no comparison crosses alpha=0.05 despite Cohen's d up to 11.5.
  • A single MLP architecture is used throughout. No comparison against gradient-boosted trees (XGBoost, LightGBM) or tabular deep architectures is included, so the ranking is conditional on this backbone.
  • Adversarial evaluation covers Dataset A only, white-box attacks only (FGSM and PGD-10), and a single adversarial-training budget (epsilon_train=0.3). Results are point estimates from single runs, without confidence intervals.
  • SHAP results are descriptive, not inferential: at most 100 explained instances per class against a 50-sample background, with no stability analysis across draws.
  • Only F1 is reported per class; precision and recall are not broken out.
  • Computational cost (training time, memory, SMOTE overhead) is not measured.
  • ADASYN, Borderline-SMOTE, and generative resampling are discussed but not evaluated.
  • The perturbable/locked feature split is a threat-model assumption, not a measured property.
