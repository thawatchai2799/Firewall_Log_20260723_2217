Explainable, Cost-Sensitive Deep Learning for Extreme Class-Imbalance Firewall Log Classification

A reproducible experimental framework for classifying firewall and network-intrusion logs under extreme class imbalance, where the security-critical classes often account for well under 1% of records. The framework compares imbalance-handling techniques and model families on three real datasets, explains predictions with SHAP, and evaluates adversarial robustness.

What this code does

The experiments are organized around four questions:

  1. Imbalance handling — Compares four techniques (baseline SMOTE, cost-sensitive learning, focal loss, hybrid SMOTE-Tomek resampling) on an identical multilayer perceptron (MLP), with Wilcoxon signed-rank tests and Cohen's d effect sizes.
  2. Cross-dataset generalization — Checks whether the technique ranking holds across datasets with different structures and class distributions, and identifies the hardest class in each.
  3. Explainability — Uses SHAP (global and local) to check that the model relies on domain-plausible features, and to profile why the hardest classes fail.
  4. Adversarial robustness — Evaluates FGSM and multi-step PGD attacks under a domain-aware perturbation constraint, and measures the effect of adversarial training.

The framework additionally compares three model families — gradient-boosted trees (XGBoost, LightGBM), the MLP, and a deep tabular network (TabNet) — to separate effects of the imbalance technique from effects of the model family.

Installation

Requires Python 3.10 or newer.

python -m venv venv
source venv/bin/activate        # on Windows: venv\Scripts\activate
pip install -r requirements.txt

Key dependencies: PyTorch, scikit-learn, imbalanced-learn, SHAP, XGBoost, LightGBM, pytorch-tabnet, matplotlib.

Datasets

The datasets are not included in this repository (they are large and separately licensed). Download them and point dataset_config.py at their locations:

Key Dataset Rows Source
ertam_kaya Internet Firewall Data Set 65,532 UCI Machine Learning Repository
cicids2017 CIC-IDS2017 (MachineLearningCVE) 2,830,743 Canadian Institute for Cybersecurity
unsw_nb15 UNSW-NB15 2,540,047 UNSW Canberra

Edit the paths at the top of dataset_config.py:

DATASET_PATHS = {
    "ertam_kaya": {"path": "path/to/log2.csv", "feature_names_csv": None},
    "cicids2017": {"path": "path/to/MachineLearningCVE/", "feature_names_csv": None},
    "unsw_nb15":  {"path": "path/to/UNSW_NB15/",
                   "feature_names_csv": "path/to/UNSW_NB15/NUSW-NB15_features.csv"},
}

All experiments read paths from this one file, so it is the only place you need to edit.

How to run

Run scripts from the repository root (so the flat module imports resolve). Each script writes a JSON result file and, where applicable, figures.

Main experiment (imbalance techniques + SHAP + FGSM):

python run_full_experiment.py

Model-family baselines:

python tree_baselines.py    --dataset ertam_kaya --path path/to/log2.csv --folds 5 --output results
python tabnet_baseline.py   --dataset ertam_kaya --path path/to/log2.csv --folds 5 --output results
python make_tree_vs_mlp_table.py --dataset ertam_kaya --results results

Follow-up analyses:

python tune_xgb_datasetA.py       --dataset ertam_kaya --path path/to/log2.csv
python pgd_attack.py              --dataset ertam_kaya --path path/to/log2.csv --steps 10
python explanation_robustness_experiment.py --dataset ertam_kaya --path path/to/log2.csv
python focal_loss_gamma_sweep.py  --dataset ertam_kaya --path path/to/log2.csv
python shap_hard_classes.py       --dataset unsw_nb15  --path path/to/unsw.csv --max_train_samples 400000
python lgbm_investigation.py      --dataset cicids2017 --path path/to/MachineLearningCVE --folds 3

Reproducibility

  • All experiments use StratifiedKFold(shuffle=True, random_state=42) and fixed global seeds.
  • Each fold applies its own StandardScaler fitted only on the training split (no leakage).
  • SMOTE is applied inside each training fold, never to the validation split.
  • Result files under results/ were produced with the configurations above and can be regenerated.

Summary of findings

  • Model family matters more than the imbalance technique. On Dataset A, class-weighted XGBoost reaches macro-F1 0.938 (10-fold) versus 0.736 for the best MLP configuration — a gap several times larger than the spread between imbalance techniques.
  • Difficulty tracks feature overlap, not rarity. The rarest classes are often among the easiest; feature-overlapped attack classes stay hard regardless of frequency.
  • A three-way family ordering. Gradient-boosted trees rank above the MLP, which ranks above the deep tabular network (TabNet), consistent with the broader tabular-learning literature.
  • Adversarial robustness has a real cost. Adversarial training cuts attack success from 97.5% to 15.5% but at a measurable clean-accuracy cost, and it shifts the model's reliance toward features an attacker cannot manipulate.
